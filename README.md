# NiceTrix

Static Astro 7 + TypeScript Content Collections + Pagefind. Production is served by Cloudflare Pages at `https://nicetrix.com`, from `AhammadAnsar/NiceTrix` on `main`. The original WordPress hosting and backups are retained; WordPress content has not been edited.

## Run

Node 24 LTS is pinned in `.node-version`. All public content and required media are included in the project; normal builds do not read WordPress, a database or the private backups.

```sh
npm ci
npm run check
npm run build
npm run preview
```

`npm run build` builds Astro, generates the actual Pagefind index and verifies the resulting content, SEO, links, image hashes and Cloudflare file budgets. Use `npm run dev` while editing; Pagefind is available in the built preview. `node scripts/serve.mjs` also previews explicit Pages redirects locally.

```sh
npx playwright install chromium
npm run test:browser
npm run test:ads
```

Browser verification covers the original URLs and media, redirects, responsive layouts at 360/390/768/1024/1440 px, mobile navigation, keyboard entry, real Bengali/English search, TOC and copy sharing. External embeds and advertisements are deliberately not contacted during automated tests. Build/browser commands regenerate ignored local `reports/build-verification.json` and `reports/browser-verification.json`. Source reconciliation is generated only when the importer runs with the separately supplied private backups; historical reports are not part of the Git repository.
